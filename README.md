# MyGameFramework

MyGameFrame是一个参照商业框架GameFrameWork的轻量级游戏框架，主要对游戏开发过程中常用模块进行了封装，很大程度地规范开发过程、加快开发速度并保证产品质量。

在最新的 Game Framework 版本中，包含以下 9 个内置模块，后续我们还将开发更多的扩展模块供开发者使用。
1.单例模块                                                                                                  
2.公共Mono模块：CPU性能优化                                                                              
3.资源加载模块(res版)                                                                                    
4.缓存池模块：CPU性能优化                                                                            
5.场景切换模块                                                                                              
6.音频模块                                                                                              
7.UI模块                                                                                                  
8.事件中心模块：低耦合                                                                                          
9.输入模块：高内聚                                                                                                

未来模块新增计划为：                                                                                                            
1.网络模块                                                                                                                    
2.对话编辑器扩展                                                                                                                
3.A星寻路模块                                                                                                              
4.数学计算工具模块                                                                                                    
等。
